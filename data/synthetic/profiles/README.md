# profiles

profiles.json contiene exclusivamente las cuatro claves y alias Perfil Demo Alfa, Beta, Gamma y Delta. progress.json contiene 18 asociaciones: 5 enrolled, 5 in_progress y 8 completed; cada perfil tiene los tres estados. Es una instantánea, no un historial de transiciones ni información de personas reales.
