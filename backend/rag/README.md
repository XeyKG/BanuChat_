# RAG

Diseño de ingesta, chunking, embeddings y recuperación sobre el corpus sintético
versionado en `/data/synthetic`. PostgreSQL + pgvector conserva datos derivados.

Las respuestas citan documento y sección; ante evidencia insuficiente se declara
la limitación. Las guías de cátedra sintéticas se sirven completas mediante enlace,
sin fragmentación ni vectorización. Proveedor y modelo de embeddings pendientes.
