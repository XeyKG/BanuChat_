# Backend

Este módulo concentra la API y la lógica del agente.

## Submodulos

- `api/`: endpoints REST para la app móvil.
- `mcp-server/`: servidor MCP para integrar herramientas externas.
- `rag/`: pipeline de ingestión, embeddings y recuperación.

## Objetivo

Orquestar el ciclo ReAct del agente, integrar herramientas y preparar el contexto semántico para la respuesta final.
